At the moment, I use Niri, a Wayland scrolling window manager.

If you've never heard of scrolling WMs, the gist is: windows are arranged in columns on an infinite strip going to the right – unlike a tiling window manager, where a workspace has to fit every window entirely. Another difference is that even if a window is the only one in a workspace, it doesn't have to occupy the entire screen, which is great for apps that don't need that much room, because they don't become unwieldily wide. In short, the scrolling approach avoids a few quirks of old-school tiling, whilst still being, in my opinion, quite superior to mainstream floating WMs that are, in comparison, unorganised and suboptimal at workspace management.

Niri, in particular, is the most established scrolling WM for a good reason – it's stable and powerful, yet not difficult to get the hang of.

I use [DankMaterialShell](https://danklinux.com/) to provide desktop functionality – elements like the top bar, launcher, control centre, dash, etc. This makes for a cohesive, out-of-the-box, quasi-desktop environment experience that is still customisable and even extendible.
